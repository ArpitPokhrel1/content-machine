    Importing into your editor

    Premiere Pro

    1. File › Import the .srt and drag it onto the timeline above your video.
    2. Select the captions track. In Essential Graphics (or Properties), set the font to Mukta.
    3. Set size and colour, then Push to track style so every subtitle matches.

    DaVinci Resolve

    1. File › Import › Subtitle, then drag it from the Media Pool onto the timeline.
    2. Click the subtitle track header, open the Inspector › Track tab.
    3. Set the font to Mukta, then size, colour and outline.

    Unicode or Preeti?

    A subtitle file can't carry a font; your editor applies it. Unicode files read as Nepali with any Unicode font. Preeti files look like g]kfn until you pick a Preeti-type font, and then they read नेपाल. That's normal. Preeti fonts can't show English letters.

    Fonts

    Turn on the fonts you use. They'll show in the font list. Nepali fonts are from anepali.com.
