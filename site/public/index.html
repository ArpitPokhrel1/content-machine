THE METHOD

Good frames begin before the prompt.

First understand what is true in the story. Then lock the details that should never drift.

✳

01 / UNDERSTAND

Find the story

Paste the whole script. Answer a focused brief about audience, mood, culture, aspect, and the ending.

▦

02 / HOLD

Lock the canon

Define subjects, environments, palette, costume, period, and constraints once. Every frame inherits them.

◩

03 / DIRECT

Shape each frame

Break the script into beats. Choose the shot, action, light, and composition. Rewrite any uncertain frame.

◉

04 / MAKE

Generate and review

Use the prompt pack with the local image operator. Inspect each image and repair one defect at a time.
