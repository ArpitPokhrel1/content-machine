Content Machine

Give your AI agent a script. Get back a folder of images and video clips that look like they came from the same film, made with your own Google account and saved on your own computer.

Reads the whole story first

It works out every character, place and period before it draws anything.

Consistent by design

One locked "look book" is pasted word for word into every prompt, so faces don't drift.

Yours, locally

It runs on your machine, bills your Cloud project, and saves files to your disk. Nothing is stored here.

Before you start

  1. An access code

    Ask the studio. It unlocks the download.

  2. A Google Cloud project with billing on

    Create one at console.cloud.google.com and link a billing account. The installer turns on Vertex AI for you. Images cost a few cents each; you're charged by Google, directly.

  3. An AI agent

    Claude Code (recommended) or Codex. The installer connects it automatically.

Install

Open a terminal, paste one line, and follow the prompts. It asks for your access code, signs you in with Google in your browser, and asks which Cloud project to use.

irm https://content.tarjun.com/install.ps1 | iex
curl -fsSL https://content.tarjun.com/install.sh | bash

Windows: use PowerShell. It installs Node.js, Google Cloud CLI and ffmpeg if they're missing (you may need to open a new window and run it again once). Mac: install Node.js and the Google Cloud CLI first.

Use it

Open Claude Code and just ask. The agent reads the method, asks its questions in one batch, then gets to work.

"Use content-machine to make a 9:16 image pack from this script: …"
"Turn frames c03 and c07 of that pack into 6-second silent clips."

Images are generated without extra questions. Video always stops first and shows you the exact clips and estimated cost, and nothing is generated until you say yes. Everything lands in ContentMachine/Outputs in your home folder.

Updating

Run the same install line again. Your settings and your Outputs folder are kept.

If something's off

In a terminal: cd ~/ContentMachine/Tool then npm run doctor -- --online. Each ✘ line says exactly what to fix. Paste the output to Claude Code if you're stuck.
