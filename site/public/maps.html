What makes these maps trustworthy

01

Real boundaries

Countries, provinces, districts and local units come from Natural Earth and geoBoundaries, open datasets used by newsrooms, with credit kept.

02

Fair on disputes

Where a border is genuinely disputed, it's drawn as a dashed line with a neutral note, never quietly settled in one side's favour.

03

No invented numbers

Every value shown on a map traces back to your data file or a named public source. Regions without data say "no data", not zero.

04

You approve the render

You see preview stills and the data sources first. The final video is made only after you say yes.

Get started

Part of Content Machine.

Maps come with the same install as Assets. You need an access code from the studio.

  1. Install Content Machine

    Follow the one-line install on the Assets page. When it asks "Also install Map Animation Studio?", answer y. Already installed? Run the same line again and say yes this time.

  2. Have Microsoft Edge or Google Chrome

    The maps are drawn in your browser engine and turned into video with ffmpeg. The installer sets up ffmpeg for you.

  3. Ask your AI assistant

    For example: "Use content-machine to animate a map zooming from Nepal into Dailekh district, 6 seconds, vertical." It asks all its map questions in one go, shows you previews, and renders after you approve.
